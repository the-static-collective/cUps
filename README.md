# cUps

> **What can U build with cups?**

cUps begins with one cup and almost no game.

The player does not enter a finished world. The player enters a world with just enough machinery to construct the next possibility.

~~~text
LOOK
  ↓
TOUCH
  ↓
MOVE
  ↓
RELATION
  ↓
TRACE
  ↓
NEW AFFORDANCE
  ↓
MORE WORLD
~~~

The long-range ambition is a phone-native construction world with systemic sandbox freedom, legible toy-box composition, and user-built games — without making engagement metrics or popularity scores the governing mechanic.

## FIRST CUP 001

Open index.html on a phone or browser.

You begin with:

- one room;
- one cup;
- one player-observer;
- one verb: **LOOK**.

The prototype unlocks later verbs through attributable interaction. Every meaningful action enters a local append-only trace rail.

The first proof question is:

> **Can playing with one cup cause the game to lawfully acquire one new possibility it did not have when the session began?**

## Four organs

### Static Workbench — construction engine

Workbench answers: **What can exist next?**

~~~text
occurrence
→ candidate relation
→ proposed affordance
→ explicit local admission
→ usable instrument
~~~

A constructed affordance begins local. One weird interaction does not silently become a universal law.

### Haunted Blender — renderer

Blender answers: **What body can this state wear?**

~~~text
world state != render
~~~

The same addressed cup may later appear as CSS, voxel geometry, stylized 3D, a cinematic take, or an observer-conditioned dream without changing its identity.

### MEMENTO — character / remembered-world interface

MEMENTO answers: **What did this observer encounter, attend to, remember, reject, or leave unresolved?**

~~~text
world occurrence
!=
character encounter
!=
attention
!=
memory
!=
belief
~~~

Future characters should inhabit local cuts of the changing world rather than query omniscient state by default.

### Full Measure — playable consequence

Full Measure answers: **Given what is lawfully here, what can become playable next?**

It may propose sparks, quests, experiments, rest, or open possibilities. It does not manufacture witnessed success.

## Phone thesis

The phone is not merely a controller.

It is the first **Pocket Body** of the world.

FIRST CUP uses ordinary touch only. Later, explicitly opt-in device capabilities may enter as separate organs.

~~~text
available
!=
enabled
!=
observed
!=
bound
!=
authorized
~~~

No sensor is required for the core game.

## Trace law

The prototype stores an append-only local JSON trace in browser storage.

~~~text
OCCURRENCE
what happened

TRACE
machine-readable receipt

MARK
what the human found interesting

PATTERN
a later proposal derived from traces
~~~

Therefore:

~~~text
trace != meaning
repetition != law
mark != canon
render != occurrence
~~~

The experiment should survive the experimental software.

## No engagement sludge

cUps should earn return through unfinished possibility, not compulsion.

No required streaks, daily-login penalties, loot boxes, follower-score hierarchy, opaque engagement ranking, or punishment for leaving.

The desired phone reflex is:

> “I wonder what happens if I try this.”

not:

> “The app says I lose something if I leave.”

## Growth curve

~~~text
LOOK
→ TOUCH
→ MOVE
→ MARK
→ COMBINE
→ MODIFY
→ BUILD
→ TOOL
→ MACHINE
→ RULE-BEARING INSTRUMENT
→ ROOM
→ WORLD
→ GAME INSIDE THE WORLD
→ CHARACTERS BUILD TOO
~~~

The construction interface should become increasingly diegetic: benches, looms, doors, books, gardens, machines and other in-world instruments instead of a separate editor.

## Current boundary

FIRST CUP 001 proves only:

1. progressive verbs;
2. one persistent addressed object;
3. append-only local traces;
4. human DELIGHT/WTF marks;
5. a first emergent affordance unlocked by witnessed interaction.

It does **not** yet claim multiplayer, AI world generation, runtime integration with the donor projects, cloud persistence, mobile sensors, account identity, or production security.

Those arrive through explicit adapters and receipts.
